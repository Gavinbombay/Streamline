## 1. Scope and Non-Goals (`L3`)

### In Scope
1. **Single-binary Rust/Axum server (`streamline`)** backed by embedded SQLite (`rusqlite`) plus optional two-way markdown directory sync (Kepano Obsidian layout).
2. **Mechanical Rule Gate (`bootstrap` + `ack_rules`)**: Sessions can read health and bootstrap rules, while write and dispatch tools remain locked until the active rule digest is acknowledged.
3. **Curated Governance Shelves & Source Passports**: Standards, Runbooks, Architecture, Projects, Skills, and Idea Inbox shelves with tag-scoped access (`granted_tags`) and per-resource Source Passports (owner, verified timestamp, freshness/drift state, lineage, next action).
4. **Redaction & Policy Gate (`streamline-safe`)**: Rejects secret-shaped tokens, high-entropy credentials, private LAN literals where public-safe mode applies, and banned identifiers (`422`) before persistence.
5. **Scalable Trio+ Engine (`P0` to `P4`)**:
   - Scores Difficulty (`D0` to `D4`) and Risk (`R0` to `R4`) to materialize the minimal complete record set (`P0` fix record through `P4` expanded commission).
   - Locks `OWN` rows upon `lock_project_plan`; worker runs can only append `DIV` divergences, never mutate `OWN` text.
   - Tracks `D -> I -> T -> A -> L` per requirement, computes `check_sync` pairings, validates `save_sync_report` evidence, and holds closeout at `DOC_PENDING_OWNER` until `HOW-IT-WORKS.md` is approved.
6. **Hands-Off Build & Cross-Model QC Conveyor (`streamline-conveyor`)**:
   - Stages declared inputs read-only, invokes configured CLI harnesses or an external worker-lease webhook, verifies post-run `CLEANUP` and zero secret scan hits, automatically dispatches an independent model family for 4-gate acceptance, and exports secret-free JSONL trajectories.
7. **Unified 3-Pane Web Workspace + Portable Skill Bundle**:
   - Serves the 3-pane UI (`sidebar / main / docked read-history-related-passport panel`), side-by-side plan comparison, pluggable Presence slot, and `/downloads/streamline-skills.zip` (`streamline-director`, `streamline-worker`, `streamline-acceptor`, `streamline-vault`).

### Out of Scope (Non-Goals)
- **No built-in paid LLM provider calls**: `Streamline` orchestrates configured external CLI harnesses or connected MCP clients; it never embeds hidden model billing or API keys.
- **No billing, payments, or commercial metering**.
- **No parallel GPU lease scheduler**: When a job requires external compute leases, `streamline-conveyor` delegates to a configured external router webhook (such as `Diffuser`) rather than scheduling GPUs itself.
- **No hardcoded private infrastructure**: Zero private hostnames, LAN addresses, or personal identifiers in code, tests, fixtures, or docs.

## 2. Critical Journeys (`L7` Summary)

Full screen states and interactions live in `UI-UX-QOL.md`:
1. **Owner First Real Journey (Slice 1)**: Start `streamline`, connect two AI clients (for example, local dashboard agent and desktop IDE agent) via MCP, call `bootstrap` + `ack_rules`, create a `P1` Trio+ project, lock `OWN` choices, record an implementation + `check_sync` report, submit `HOW-IT-WORKS.md`, and approve closeout.
2. **Hands-Off Conveyor Journey (Slice 2)**: Dispatch a locked project slice; `Streamline` mounts inputs read-only, runs builder CLI, verifies cleanup and redaction, automatically triggers a different model family for QC, and lands in `DOC_PENDING_OWNER` without manual babysitting.
3. **Scoped Guest / Project Agent Journey (Slice 3)**: Issue a tag-scoped token (`project:demo`, `standards`); verify the caller can read granted shelves and submit bounded work while receiving `403` on ungranted shelves with zero capacity consumed.

## 3. Falsifiable Critique (`L11`)

| Risk | How It Fails | Verification / Retirement Test |
| :--- | :--- | :--- |
| **Bypassing Rule Gate** | Agent calls `save_resource` or `dispatch_run` before acknowledging current `RULES` digest, or after `RULES` changes. | Integration test proves `412 Precondition Failed` (`RULES_ACK_REQUIRED`) until `ack_rules` matches current digest. |
| **Silent `OWN` Erosion** | Worker overwrites an approved owner requirement inside `save_project_documents` after Plan Lock. | Database trigger / service guard rejects edits to locked `OWN` rows (`409 OWN_LOCKED`) and requires `record_divergence`. |
| **Same-Family Self-Grading** | Conveyor assigns QC acceptance (`R2+`) to the same harness/model family that ran the build. | Conveyor scheduler test proves `builder_family == acceptor_family` is rejected (`422 SAME_FAMILY_FORBIDDEN`). |
| **Secret or Identity Leak into Vault/Repo** | Agent writes a raw bearer token, private key, or restricted identifier into a doc or `HOW-IT-WORKS.md`. | `streamline-safe` unit + HTTP/MCP negative suite proves `422 REDACTION_BLOCKED` with zero bytes persisted. |
| **Vault Sync Split-Brain** | Direct edit to an Obsidian markdown file conflicts with an in-DB revision. | Sync engine hashes both sides (`base_sha256`), imports clean external edits as new revisions, and flags concurrent edits as explicit conflict records rather than overwriting silently. |
